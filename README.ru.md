# NexaGate

Панель управления с маршрутами Hysteria2, VLESS XHTTP Reality, VLESS XHTTP TLS, RAW Reality и WebSocket TLS.

## Быстрый старт

Установка выполняет проверку и установку зависимостей автоматически:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/MehrooExplains/nexagate/main/install.sh)
```

После установки откройте HTTPS-панель и используйте ссылки или QR-коды пользователей. TCP-трафик направляется через Psiphon, UDP — через WARP. Существующие конфигурации обновляются автоматически и безопасно.

Полная документация доступна на [английском](README.md) и [фарси](README.fa.md).
